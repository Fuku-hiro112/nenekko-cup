# ねっこ杯 ポカジャン大会 案内サイト

Discord「ねっこ集会所」で開催する、ホロドリのミニゲーム **ポカジャン** の大会案内ページです。
ビルド不要の素の HTML / CSS / JS で作られています。

```
nenePokajyan/
├─ index.html        すべての文言はここに直接書かれています
├─ assets/
│   ├─ style.css     配色・レイアウト・演出
│   ├─ script.js     画像スロット / カウントダウン / スクロール表示 / モバイルメニュー
│   └─ img/          画像を置く場所（README あり・初期状態は空）
├─ tools/
│   └─ generate_nene.py   キャラクタービジュアルをSDで生成するスクリプト
└─ README.md
```

## キャラクタービジュアルを生成する

`tools/generate_nene.py` で、ローカルの Stable Diffusion WebUI Forge から
ヒーロー用の画像を生成できます。生成後は白背景を自動で透過にして `assets/img/nene.png` に保存します。

**Forge は `start_forge_api.bat` から起動してください。** 通常の起動方法だと `--api` が付かず、
スクリプトから生成を実行できません。

生成スクリプトは2つあり、**どちらでも同じ画像が出ます**（seed 固定でバイト単位の一致を確認済み）。

- **共有版（推奨）** — `illust-forge` Skill 同梱。設定は本プロジェクトの `sd-images.json`
- **専用版** — `tools/generate_nene.py`。プロンプトを直書きした最初の版

```
# 共有版（設定は sd-images.json を自動で探す）
python ../.claude/skills/illust-forge/scripts/sd_generate.py --list
python ../.claude/skills/illust-forge/scripts/sd_generate.py --preset hero
python ../.claude/skills/illust-forge/scripts/sd_generate.py --preset about --count 4
python ../.claude/skills/illust-forge/scripts/sd_generate.py --preset hero --seed 4142397257
python ../.claude/skills/illust-forge/scripts/sd_generate.py --preset ogp

# 専用版
python tools/generate_nene.py --list
python tools/generate_nene.py --preset hero
```

共有版は `sd-images.json` の `subject` に `$桃鈴ねね` と書くだけで、Forge の変数マネージャの定義
（`vars/variables.json`）から自動展開します。定義を二重管理しなくて済みます。

| プリセット | 出力 |
|---|---|
| `hero` | `nene.webp` — カードを見せているポーズ |
| `about` | `nene-about.webp` — 説明しているバストアップ |
| `entry` | `nene-entry.webp` — 招いているポーズ |
| `splash` | `nene-splash.webp` — 顔まわりのアップ |
| `nekko` | `nekko.webp` — ファンマスコット「ねっこ」 |
| `chibi` | `chibi.webp` — 二頭身のねね |
| `ogp` | `ogp.jpg` — 1200×630 の合成画像 |

キャラクターのプロンプトは Forge の変数マネージャの `$桃鈴ねね` 定義をそのまま使っています。
ポーズや構図は `PRESETS` の `pose` を書き換えれば変えられます。

生成後は「白背景の透過 → 孤立した塊の除去 → 余白のトリミング → 表示サイズへの縮小 → WebP保存」を
自動で行います。採用中の画像のseedは以下のとおりです。

| プリセット | seed |
|---|---|
| hero | 4142397257 |
| about | 4256552969 |
| entry | 2184834421 |
| splash | 3473462233 |
| nekko | 1043805195 |

## 表示する

`index.html` をダブルクリックしてブラウザで開くだけです。サーバーは要りません。

## PCでモバイル表示を確認する

`tools/preview-mobile.html` を開くと、**実物のページをスマホの幅のまま枠の中に表示**します。
端末幅を切り替えるボタンつきで、スクロールも動作も本物と同じです。

このページは iframe を使うため、ファイルを直接開くのではなく簡易サーバー経由で見てください。

```
# プロジェクトのフォルダで
python -m http.server 8931
```

ブラウザで <http://127.0.0.1:8931/tools/preview-mobile.html> を開きます。

Chrome の DevTools でも同じことができます（`F12` → `Ctrl`+`Shift`+`M`）。
そちらは実機に近いタッチ操作のエミュレートまでできるので、細かく見たいときはDevToolsのほうが確実です。

### 日付を直すときの注意

開催日時は**3か所**に書いてあります。片方だけ直すとズレるので、必ず全部を揃えてください。

1. 手札1・2枚目（`9/13` と `21:00`）
2. ABOUT の「開催日時」
3. カウントダウンの `data-deadline`（ISO形式。ここだけ書式が違います）

締切も**手札7枚目とENTRYの2か所**にあります。

カウントダウンは開催日時を過ぎると自動的に消えます。

### 背景の幕

ヒーローでは20秒ごとに、ねっ子を散らした幕が右から滑り込み、少し止まってから真ん中で左右に開いて壁紙が現れます。

- **幕は背景だけにかかります。** 大会名・キャッチ・カウントダウン・手札は常に幕の手前に出ます（幕は `z-index:1`、中身は `z-index:2`）
- そのため幕自体は文字を持ちません。**地は必ず明るい色にしてください。** 濃い色にすると、手前の濃い文字が読めなくなります（実際に一度そうなりました）
- 間隔を変えるなら `style.css` の `.js .curtain__half--l / --r` の `20s` を書き換えます
- **開幕の1回だけ**にしたい場合は、同じ行の `infinite` を消してください

`prefers-reduced-motion` の端末と、`script.js` が読み込めなかった場合は幕そのものが出ません。

### 流れる帯の文字

ヒーローの下を流れる帯は、同じ内容を2セット並べることで途切れず繋がっています。文字を変えるときは
`<span class="marquee__set">` **2つとも同じ内容**にしてください。片方だけ変えると流れが飛びます。

### 大会名を変えるときの注意

大会名は白フチをきれいに出すために、同じ文字列を 2 か所に書いています。**両方**を同じ文字列にしてください。

```html
<span class="stroked" data-text="ポカジャン大会">ポカジャン大会</span>
                      ^^^^^^^^^^^^^^^^^^^^^^^^^^  ^^^^^^^^^^^^^^
                      ここと                        ここを同じに
```

### エントリーボタンのリンク

ENTRY セクションのボタンは初期状態で `href="#"`（リンク先なし）です。
Discord の招待リンクや募集メッセージの URL に差し替えてください。

```html
<a class="btn btn--primary btn--lg" href="#" target="_blank" rel="noopener noreferrer">
```

## ページの重さ

初回表示でおよそ **1.2MB**（画像 373KB ／ フォント約 750KB ／ HTML・CSS・JS 約 60KB）。
2回目以降はブラウザのキャッシュが効きます。

大半を占めるのは Google Fonts の日本語フォントです。もっと軽くしたい場合は、
本文用の Zen Kaku Gothic New をやめて見出し用の Zen Maru Gothic だけにすると
半分近く減りますが、長文の読みやすさは落ちます。

なお Google Fonts は**画面に実際に出た文字が属するサブセットだけ**を落とすため、
`<link>` に使わないウェイトを並べてもフォント本体の転送量は増えません。

## 技術メモ

- 外部依存は Google Fonts（Zen Maru Gothic / Zen Kaku Gothic New / Outfit）のみです。読み込みに失敗しても端末標準のゴシックにフォールバックします。
- 文言は JS で流し込んでいません。JavaScript が無効でも全内容が読めます。
- **ローディングと配牌はCSSだけで動きます。** `script.js` の読み込みに失敗しても、手札や本文が隠れたままになることはありません（`.js` と `.anim` の2つのクラスで役割を分けています）。
- `script.js` が担当するのは、画像スロット・カウントダウン・スクロール表示・ヘッダー・モバイルメニューだけです。
- 画像は「読み込めたものだけ表示する」仕組み（`data-img-slot`）です。ファイルが無くても壊れた画像アイコンは出ません。`data-reveals` と `data-img-group` で、見出しごと消す／出すを制御しています。
- **スロット内の画像に `loading="lazy"` は付けないでください。** `hidden` な要素は画面に入らないため、遅延読み込みが永久に発火せず、画像が出なくなります。
- `prefers-reduced-motion: reduce` を設定している端末では、ローディング・配牌・花びら・流れる帯・スクロール演出・**壁紙の出入り・ねっ子のにょきにょき**をすべて止めて静止表示にします。
- ヒーローの壁紙には可読性のための膜（`::after` の白いグラデーション）をかけています。**画像を差し替えたら、キャッチコピーと「開催まであと」のコントラストを測り直してください**（現状 13.4:1 / 6.3:1）。
- ブラウザのダークモード強制に備えて `color-scheme: light` を指定し、`html` と `body` の両方に背景色と文字色をセットで指定しています。
