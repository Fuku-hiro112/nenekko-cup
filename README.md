# ねっ子ポカジャン大会 案内サイト

Discord「ねっこ集会所」で開催する、ホロドリのミニゲーム **ポカジャン** の大会案内ページです。
ビルド不要の素の HTML / CSS / JS で作られています。

## 見る

`index.html` をダブルクリックするだけです。サーバーは要りません。

## ファイル構成

```
nenePokajyan/
├─ index.html          ページ本体。文言はすべてここに直接書かれています
├─ README.md           このファイル
├─ sd-images.json      画像生成の設定（ルート固定。動かさないでください）
├─ assets/
│   ├─ style.css       配色・レイアウト・演出
│   ├─ script.js       画像スロット / カウントダウン / スクロール表示 / メニュー
│   └─ img/            ページが読み込む画像 18点
├─ docs/               設計書（下記）
└─ tools/
    ├─ generate_nene.py    キャラクター画像の生成スクリプト
    ├─ cut_cards.py        RULEの札をプレイ画面から切り出すスクリプト
    ├─ draw_tables.py      卓分けの抽選（下記）
    ├─ update_bracket.py   トーナメント表を index.html に書き込む（下記）
    ├─ build_operation_xlsx.py  運営ガイドの Excel 版を書き出す
    ├─ participants.example.csv  参加者CSVの書きかたの見本
    ├─ preview-mobile.html PCでスマホ表示を確認する枠
    └─ src-img/            加工前の原本（Gitには乗りません）
```

**ルート直下にファイルを増やさないでください。**
`assets/` はブラウザが読むもの、`tools/` は制作に使うもの、`docs/` は人が読むものです。

## よく直すところ

**1. 応募フォームのURL（未設定）**

ENTRY のボタンが `href="#"` のままです。`index.html` で
`<!-- EDIT: ここをGoogleフォームのURLに差し替えてください -->` を探してください。

**2. 文言を変える**

`index.html` に `<!-- EDIT: 〜 -->` というコメントが **33か所** あります。
その直後が書き換えてよい場所です。エディタで `EDIT:` を検索すると全部に飛べます。

**3. 開催日時を変える**

日時は**9か所**に書かれています。1つでも直し忘れると矛盾するので、
[詳細設計書 2-2](docs/detail-design.md#2-2-開催日時を変える重要9か所あります) の一覧を見ながら
全部そろえてください。

> 変更したあとは、詳細設計書の末尾にある**チェックリスト**で確認してください。

## 大会を運営する

**卓分けの抽選から当日の更新までは [大会運営ガイド](docs/operation-guide.md) にまとめてあります。**
実際に表示される内容つきの手順書なので、当日はそれを開きながら進めてください。

```bash
# 前日：抽選して保存する
python tools/draw_tables.py 参加者.csv --save tournament.json

# 当日：tournament.json の winners に勝った人を書いてから
python tools/update_bracket.py tournament.json
```

これでトーナメント表が更新され、次の回戦も自動で組まれます。
Googleフォームの回答CSVは、**列を並べ替えずそのまま渡せます。**
