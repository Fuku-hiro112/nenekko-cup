# ねっ子ポカジャン大会 案内サイト

Discord「ねっこ集会所」で開催する、ホロドリのミニゲーム **ポカジャン** の大会案内ページです。
ビルド不要の素の HTML / CSS / JS で作られています。

## 見る

`index.html` をダブルクリックするだけです。サーバーは要りません。

## ファイル構成

```
nenePokajyan/
├─ index.html          ページ本体。文言はすべてここに直接書かれています
├─ README.md           このファイル
├─ sd-images.json      画像生成の設定（ルート固定。動かさないでください）
├─ assets/
│   ├─ style.css       配色・レイアウト・演出
│   ├─ script.js       画像スロット / カウントダウン / スクロール表示 / メニュー
│   └─ img/            ページが読み込む画像 18点
├─ docs/               設計書（下記）
└─ tools/
    ├─ generate_nene.py    キャラクター画像の生成スクリプト
    ├─ cut_cards.py        RULEの札をプレイ画面から切り出すスクリプト
    ├─ draw_tables.py      卓分けの抽選（下記）
    ├─ participants.example.csv  参加者CSVの書きかたの見本
    ├─ preview-mobile.html PCでスマホ表示を確認する枠
    └─ src-img/            加工前の原本（Gitには乗りません）
```

**ルート直下にファイルを増やさないでください。**
`assets/` はブラウザが読むもの、`tools/` は制作に使うもの、`docs/` は人が読むものです。

## よく直すところ

**1. 応募フォームのURL（未設定）**

ENTRY のボタンが `href="#"` のままです。`index.html` で
`<!-- EDIT: ここをGoogleフォームのURLに差し替えてください -->` を探してください。

**2. 文言を変える**

`index.html` に `<!-- EDIT: 〜 -->` というコメントが **32か所** あります。
その直後が書き換えてよい場所です。エディタで `EDIT:` を検索すると全部に飛べます。

**3. 開催日時を変える**

日時は**10か所**に書かれています。1つでも直し忘れると矛盾するので、
[詳細設計書 2-2](docs/detail-design.md#2-2-開催日時を変える重要10か所あります) の一覧を見ながら
全部そろえてください。

> 変更したあとは、詳細設計書の末尾にある**チェックリスト**で確認してください。

## 卓分けを抽選する

応募が締め切られたら、参加者リストから1回戦の卓分けを決めます。

```bash
python tools/draw_tables.py 参加者.csv              # 抽選して表示
python tools/draw_tables.py 参加者.csv --md         # Discordに貼れる形で出す
python tools/draw_tables.py 参加者.csv --seed 12345 # 同じ結果を出し直す
```

CSV は `名前,解放` の2列です。書きかたは `tools/participants.example.csv` を見てください。
2列目が空欄・「未」「未解放」「×」などなら未解放、それ以外は解放済みとして扱います。

サイトに書いてあるルールをそのままコードにしてあります。

- **各卓に解放している人が必ず1人入ります**（ルームを作る人が要るため）
- 4人に満たない卓の空席にはCPUが入るので、その席数も表示します
- 参加人数から段数（1回戦→2回戦→決勝）を試算します

> **抽選結果は毎回変わります。** 確定させたいときは表示された seed を控えて、
> `--seed` で渡し直してください。同じ並びが再現できます。

決勝が4人に満たない組み合わせのときは注意が出ます。`--advance`（各卓から
何名が勝ち上がるか。既定は2名）を変えて調整してください。
