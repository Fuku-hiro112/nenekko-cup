# 画像ガイド

画像の**置き場所・作りかた・使ってよい画像の線引き**をまとめた文書です。

---

## 1. フォルダの使い分け

| フォルダ | 入れるもの | Gitに乗るか |
|---|---|---|
| `assets/img/` | **ページが実際に読み込む画像だけ**（軽いWebP / JPG） | 乗る |
| `tools/src-img/` | 加工前の原本（重いPNG / JPG） | **乗らない**（`.gitignore`） |
| ルート直下 | **画像を置かない**（`.gitignore` で弾いています） | — |

確認用のスクリーンショットは、**プロジェクトのフォルダの外**に保存してください。

## 3. キャラクター画像を作り直す

ローカルの Stable Diffusion WebUI Forge から生成します。
**Forge は `start_forge_api.bat` から起動してください。** 通常の起動方法だと `--api` が
付かず、スクリプトから生成できません。

生成スクリプトは2つあります。キャラクター画像は**どちらでも同じものが出ます**
（seed固定でバイト単位の一致を確認済み）。

> **ただし OGP だけは違います。** 専用版（`tools/generate_nene.py`）は文字を
> スクリプトに直書きしており、`sd-images.json` を読みません。
> **OGP を作り直すときは必ず共有版を使ってください**（章4）。

```bash
# 共有版（推奨）— illust-forge Skill 同梱。設定はルートの sd-images.json を自動で探す
python ../.claude/skills/illust-forge/scripts/sd_generate.py --list
python ../.claude/skills/illust-forge/scripts/sd_generate.py --preset hero
python ../.claude/skills/illust-forge/scripts/sd_generate.py --preset hero --seed 4142397257
python ../.claude/skills/illust-forge/scripts/sd_generate.py --preset about --count 4

# 専用版 — プロンプトを直書きした最初の版
python tools/generate_nene.py --list
python tools/generate_nene.py --preset hero
```

> `sd-images.json` は **ルート直下から動かさないでください。**
> スクリプトがカレントディレクトリから上へ向かって探すため、
> サブフォルダに置くと毎回 `--config` の指定が必要になります。

### プリセット

`sd-images.json` の `presets` で定義しています。

| プリセット | 出力 | いまページで使っているか |
|---|---|---|
| `hero` | `nene.webp` | **使用中**（ABOUT） |
| `about` | `nene-about.webp` | 未使用 |
| `entry` | `nene-entry.webp` | 未使用 |
| `mascot` | `nekko.webp` | 未使用（`nekko-1〜3` は手描き原本から加工） |
| `ogp` | `ogp.jpg` | **使用中**（章4） |

`about` / `entry` / `mascot` は定義だけ残してあります。使いたくなったら
`index.html` に `data-img-slot` の枠を足せば表示できます。

採用中の画像の seed：

| プリセット | seed |
|---|---|
| hero | 4142397257 |
| about | 4256552969 |
| entry | 2184834421 |
| mascot | 1043805195 |

キャラクターのプロンプトは Forge の変数マネージャの `$桃鈴ねね` 定義をそのまま
使っています（`sd-images.json` に `"subject": "$桃鈴ねね"` と書くだけで展開されます）。
ポーズや構図を変えたいときは、同じファイルの `pose` を書き換えてください。

生成後は「白背景の透過 → 孤立した塊の除去 → 余白のトリミング →
表示サイズへの縮小 → WebP保存」を自動で行います。

### 透かしに注意

このモデルは、画像の隅に署名や **「© COVER Corp」風の偽の著作権表記** を描くことがあります。
そのまま載せると公式と誤解されます。

- ネガティブプロンプトで強く抑制しています（`sd-images.json` の `negative`。**ここを弱めないでください**）
- 生成スクリプトが、切り抜き後に孤立した小さな塊を自動で除去します
- それでも取りこぼすことがあるので、**採用前に必ず画像の四隅を目視で確認してください**

## 4. リンクプレビュー画像（OGP）を作り直す

Discord に URL を貼ったときに出る 1200×630 の画像です。

```bash
python ../.claude/skills/illust-forge/scripts/sd_generate.py --preset ogp
```

**この処理は Forge を起動していなくても動きます。** `assets/img/nene.webp` と
`sd-images.json` の `ogp` セクションの文字を合成するだけだからです。

> **`tools/generate_nene.py --preset ogp` を使わないでください。**
> そちらは文字がスクリプトに直書きされていて `sd-images.json` を読まないため、
> 設定を直しても画像に反映されません。**日付だけ古いOGPができます**（実際に踏みました）。

`ogp` セクションの `lines` に、表示する文字・位置・サイズ・色を書きます。
**大会名や日時を変えたら、ここも直して画像を作り直してください。**
`index.html` のテキストだけ直しても、リンクプレビューは古いままになります。

## 5. ゲーム画面のスクリーンショット

RULE セクションに並ぶ2枚です。差し替えるときは同じファイル名で
`assets/img/` に置いてください。

| ファイル名 | 写っているもの |
|---|---|
| `board-play.webp` | 対局中の画面（手札・山札・役の一覧・他家のコイン） |
| `board-cards.webp` | 対局前に出る「今回登場するグループ」の画面（グループ一覧とBONUS） |

- **他人のIDや個人情報が写り込んでいないか、置く前に確認してください**
- 1枚も置かなければ、RULE の「実際の画面」ブロックごと消えます
  （フッターの著作権表記も連動して消えます）
- 説明文は `index.html` の `<!-- EDIT: 盤面の説明1 / 2 -->` で変えられます
- 2枚は**同じ大きさの枠**に並びます。**横長のスクショを想定**しています。
  縦長の画像を入れると、枠の高さに合わせて小さく表示されます

### 役と賞の説明に使う札（10枚）

「役の作りかた」の3枚のカードと「ねねち賞」に並ぶ札は、すべてプレイ画面からの切り出しです。

| ファイル名 | 何を写しているか |
|---|---|
| `yaku-same-1〜3.webp` | 手札にそろった**同じホロメン3枚**（枠の色は違っていて構いません） |
| `yaku-group-1〜4.webp` | 盤面の役一覧にある、**あるグループの全員** |
| `yaku-wait-1〜2.webp` | あと1枚で成立する状態の**そろっている2枚** |
| `yaku-nene.webp` | **青い桃鈴ねね**が1枚。ページ側で3つ並べて「同じ色で3枚」を表しています |

> `yaku-nene.webp` だけ**同じファイルを3回読み込んでいます。** 3枚そろった実際の画面が
> 無いためで、賞の条件（同じ色で3枚）を絵で見せるための組み立てです。
> 実物の画面が撮れたら、3枚を別々に切り出して差し替えてかまいません。

- 高さ130pxで書き出しています（表示は76pxなので約1.7倍）
- 縦横比はバラバラでかまいません。`object-fit: contain` で全体が入ります
- 枚数を増減するときは `index.html` の `.yaku__hand` に
  `<span class="mini mini--card">` を足し引きしてください（4枚までは並びが崩れません）

この9枚と `board-cards.webp` は、**切り出しスクリプトで作り直せます。**

```bash
python tools/cut_cards.py                 # assets/img/ に上書き
python tools/cut_cards.py <確認用フォルダ>  # 別の場所に出して見比べる（_sheet.png 付き）
```

切り出す座標はスクリプトの `JOBS` に原本のピクセルで書いてあります。
**原本を撮り直したら座標も取り直してください。** 手札は隙間なく並んでいるので、
左右を2pxずつ内側に寄せて隣の札の縁を拾わないようにしています。

## 6. 使ってよい画像・いけない画像

このサイトは [ホロライブプロダクション二次創作ガイドライン](https://hololivepro.com/terms/)
に沿って、非営利で運営する前提です。

**置いてよいもの**

- 自分で描いた、または自分で生成したファンアート
- 描き手から掲載の許諾をもらったファンアート
- 自分のプレイ画面のスクリーンショット

**置いてはいけないもの**

- 公式サイト・公式X・配信画面などから取ってきた**公式イラスト、公式ロゴ、公式グッズ写真**
- 他人のファンアートを無断で持ってきたもの
- 攻略サイトなど、他サイトに載っている画像

ガイドラインは「創意工夫のある創作」を非営利で認めるものです。公式素材の著作権は
カバー株式会社が留保しており、転載は認められていません。
**「公式と誤解されうるもの」も禁止事項**です（章3の透かしに注意するのはこのためです）。

## 7. ファイル形式

キャラクターの切り抜きは **WebP**（透過つき）です。
同じ絵柄で PNG の約 1/6 に収まるため採用しています。主要ブラウザはすべて対応済みです。

差し替えるときも WebP を推奨しますが、PNG でも動きます。
その場合は `index.html`（および幕の柄なら `style.css`）の拡張子も合わせて変更してください。

## 8. 他の方のイラストを使う場合

許諾を得て使うときは、`index.html` のフッター（`<!-- EDIT: 問い合わせ先 -->` の近く）に
「イラスト：〇〇さん」の1行を足してください。
