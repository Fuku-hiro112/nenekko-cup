### 2-7. ルールの説明をどこまで自分で書くか

**点数計算・役ごとのコイン・順位倍率は、このサイトには書いていません。**
数字が変わったときに追随できず、間違ったまま残るからです。実際、以前は
「同じ期生のカードが3枚そろえば成立」と書いていましたが、正しくは
**そのグループのホロメンを全員分そろえる**役でした。

代わりに RULE 末尾の**参考リンク**（`.refs`）から、実際のゲーム画面つきで
解説している攻略サイトへ送り出しています。

| このサイトに書くこと | 外部リンクに任せること |
|---|---|
| ゲームの雰囲気、役が2種類あること、ゲーム画面 | 点数、順位倍率、役ごとの細かい条件、勝つコツ |
| **この大会のルール**（ねねち賞・卓分け・結果報告） | — |

判断の目安は「**リンクが全部切れても大会が成立するか**」です。
参加者が当日そのまま座るのに要る情報だけを自前で持ち、それ以外は外に出します。

リンク先は**2本**あります。片方が消えても、もう片方が残るようにするためです。
両方切れたらカードごと削除してかまいません（見出しと注記も一緒に消してください）。
数字を自分で書き足したくなったら、**まず出典を確認してから**にしてください。

## 3. HTML構造の契約

`index.html` と `script.js` の間の約束事です。**これを崩すと動かなくなります。**

### 3-1. 画像スロット

```html
<span class="…" data-img-slot hidden>
  <img src="assets/img/○○.webp" alt="">
</span>
```

| 属性 | 意味 |
|---|---|
| `data-img-slot` | 画像1枚ぶんの枠。初期状態は `hidden` |
| `data-reveals="名前"` | 読み込めたら、その名前のまとまりも一緒に表示する |
| `data-img-group="名前"` | まとまり側の要素（見出しやブロック全体） |

`script.js` が `img.naturalWidth > 0` を確認してから `hidden` を外します。
ファイルが無ければ `hidden` のままなので、壊れた画像アイコンは出ません。

現在使っているグループは `shots`（RULEのゲーム画面）だけです。
画面が1枚も置かれていなければ、見出しごと消え、フッターの著作権表記も出ません。

### 3-2. カウントダウン

```html
<div class="countdown" hidden data-deadline="2026-08-14T21:00:00+09:00">
  <span class="countdown__cell"><b data-unit="days">--</b><i>日</i></span>
  …
</div>
```

`data-unit` は `days` / `hours` / `minutes` の3つ。`data-deadline` は ISO形式のみ
（`Date` でパースできない書式だとカウントダウン全体が出ません）。

### 3-3. セクションid

`#top` `#about` `#rule` `#flow` `#entry` の5つ。ヘッダーのナビと対応しています。
**idを変えるならナビのリンクも変えてください。**

### 3-4. `.reveal` クラス

付いたセクションだけがスクロール表示の対象になります。
中身は `.wrap` / `.yaku` / `.localrule` / `.steps` の**直下の子要素**が
順にずれて出ます。これ以外のコンテナを使うと演出がかかりません。

## 5. 二重に書いてある箇所（片方だけ直すと壊れる）

### 5-1. 開催日時 → 9か所（章2-2）

### 5-2. 大会名の `data-text`

白フチをきれいに出すため、同じ文字列を2か所に書いています。

```html
<span class="stroked" data-text="ポカジャン大会">ポカジャン大会</span>
                      ^^^^^^^^^^^^^^^^^^^^^^^^^  ^^^^^^^^^^^^^^
                      ここと                       ここを同じに
```

`data-text` は `::before` で縁取り用に描画されます。ズレると二重に文字が見えます。

### 5-3. 流れる帯（**二重に書く必要はありません**）

`<span class="marquee__set">` は **HTMLに1つだけ**書いてください。
足りないぶんは `script.js`（章7の6）が複製します。文言を直す場所も1か所です。

以前は同じ内容を2つ並べていましたが、**1セットが画面幅より狭いと折り返す直前に
右側が空く**不具合がありました（1セット982px・画面1674pxで、右に692pxの空白）。
帯は「1セット分だけ左へ動かして、次のセットが同じ位置に来たら折り返す」作りなので、
**動く1セット分に加えて、画面を覆えるだけのセットが要る**からです。

いまは画面幅から必要数を出して複製し、その数を `--marquee-sets` に入れています。
CSS側の移動量は `100% ÷ セット数`＝常に1セット分なので、
**セットが何個に増えても流れる速さは変わりません。**

### 5-4. 手札の `--i`

```html
<li class="hand__tile" style="--i:0">   … 1枚目
<li class="hand__tile" style="--i:1">   … 2枚目
```

`--i` が配牌アニメの順番（`80ms × --i` の遅延）です。
札を足す・消すときは **0から連番で振り直してください。** 番号が飛ぶと配られる間が空きます。

### ヘッダーの組み立て（章4）

ヘッダーは3つの要素でできています。いずれも本文の造作から借りた形なので、
本文側の色や形を変えたときはここも見てください。

| 要素 | 何を借りているか |
|---|---|
| 地の斜めストライプ | RULE セクションの「牌の裏面」の柄（刻みだけ 7/20px と細かい） |
| 下辺の金の帯（`.site-header::after`） | 本文カードが上辺に持っている帯と同じグラデーション |
| ロゴの札（`.site-header__logo`） | RULE の `.mini`（小さな札）の地・縁・角丸 |
| ENTRY のピル（`.site-nav__cta`） | `.btn--primary` の「沈み込む」影の付けかた |

ENTRY だけ見た目を変えているのは、**このページの目的が応募だから**です。
装飾ではなく導線なので、他の項目と同じ重さにはしていません。

### レスポンシブの断点は2つだけ

| 断点 | 変わること |
|---|---|
| `max-width: 900px` | ABOUT が1カラムに。役・ルール・ゲーム画面が縦積みに |
| `max-width: 760px` | ハンバーガーメニューが出る。**手札の扇が2列グリッドに**。装飾を間引く。見出しの金罫線を消す。配牌が横からでなく下から出るようになる |

**モバイルを直すときは 760px 側を見てください。** ほとんどの調整はここに入っています。

### 章15「モーション低減」

`prefers-reduced-motion: reduce` の端末向けに、動きをすべて止める章です。
**新しくアニメーションを足したら、この章にも止める指定を追加してください。**
特に無限ループするものは、放置すると 0.01ms で回り続けてCPUを食います。

## 7. JavaScript の仕様

`script.js` は演出とナビゲーションだけを担当します。**文言は一切扱いません。**
即時実行関数1つの中に6つの機能が順に並んでいます。

| # | 機能 | 入力 | 出力 | 失敗したとき |
|---|---|---|---|---|
| 0 | `.anim` 付与 | — | `<html>` に `.anim` | JSが動かなければ付かない＝reveal で隠れない |
| 1 | 画像スロット | `[data-img-slot]` | `hidden` を外す | 画像が無ければ枠ごと出ない（正常動作） |
| 2 | カウントダウン | `.countdown[data-deadline]` | 日・時・分を30秒ごと更新 | 日時が不正／過去なら `hidden` にして終了 |
| 3 | reveal | `.reveal` | `.is-visible` を付与（一度きり） | IntersectionObserver 非対応なら最初から全表示 |
| 4 | ヘッダー | `window.scrollY` | `scrollY > 40` で `<html>` に `.is-scrolled` | — |
| 5 | モバイルナビ | `.nav-toggle` / `#site-nav` | `aria-expanded` と `.is-open` を切替 | 要素が無ければ何もしない |
| 6 | 流れる帯 | `.marquee__set` 1つと画面幅 | 足りないぶんを複製し `--marquee-sets` を設定 | 複製されず1セットのまま（帯は静止するが文字は読める） |

ナビはリンクをクリックしたときと `Escape` キーで閉じます。

帯は画面の**幅**が変わったときだけ組み直します（200ms待ってから）。
スマホでアドレスバーが開閉して高さだけ変わるケースでは組み直しません。
Webフォントの読み込みで文字幅が変わるため、`document.fonts.ready` でも測り直します。

## 8. 落とし穴集（触ると壊れる箇所）

過去に実際に踏んだもの、踏みそうなものです。

| # | やってはいけないこと | 何が起きるか |
|---|---|---|
| 1 | スロット内の `<img>` に `loading="lazy"` を付ける | `hidden` な要素は画面に入らないため遅延読み込みが**永久に発火せず**、画像が出なくなる |
| 2 | 幕（`.curtain__panel`）の地を濃い色にする | 手前の濃い文字が読めなくなる（一度やらかしています） |
| 3 | `data-text` と表示文字をズラす | 縁取りが二重に見える |
| 4 | `.marquee__set` を手で2つ以上並べる | JSがさらに複製するので帯が無駄に長くなる。**HTMLには1つだけ**（章5-3） |
| 5 | 手札の `--i` を飛ばす／付け忘れる | 配られる間が空く／その札だけ最初から見えている |
| 6 | 日時を一部だけ直す | ページ内で日付が矛盾する（章2-2の9か所＋OGP画像） |
| 7 | フッターの非公式注記・ガイドラインリンクを消す | ガイドライン違反になる |
| 8 | `style.css` の画像パスに `assets/` を付ける | 幕の柄が出なくなる（CSSからの相対パスは `img/…`） |
| 9 | ルート直下に `.png` を置く | 散らかる。`.gitignore` で弾いているのでGitにも乗らない |
| 10 | 新しいアニメを足して章15に追記しない | 「動きを減らす」設定の端末で止まらない |
| 11 | `.site-nav ul` の `align-items: center` をレスポンシブ側で戻し忘れる | 横並び用の指定なので、縦に積むスマホでは項目が中身の幅まで縮み、**ENTRY のピルが伸びない**（実際に踏みました） |
| 12 | ヘッダーのロゴ札の文字を増やす／`white-space: nowrap` を外す | スマホで札が2行になり、**ヘッダーの高さ（62px）からはみ出す** |
| 13 | `<!-- BRACKET:START -->` / `<!-- BRACKET:END -->` を消す | `update_bracket.py` が書き込み場所を見つけられず止まります。**この間を手で直しても、次の実行で消えます** |

## 9. 動作確認の手順

### PC で見る

`index.html` をダブルクリックするだけです。サーバーは要りません。

### スマホ表示を PC で見る

`tools/preview-mobile.html` は **実物のページをスマホ幅のまま枠の中に表示**します。
iframe を使うので、**簡易サーバー経由**で開いてください。

```
# プロジェクトのフォルダで
python -m http.server 8931
```

→ <http://127.0.0.1:8931/tools/preview-mobile.html>

Chrome の DevTools（`F12` → `Ctrl`+`Shift`+`M`）でも同じことができます。
タッチ操作までエミュレートできるので、細かく見たいときはこちらが確実です。

### スクリーンショットの置き場所

**プロジェクトのフォルダ内には保存しないでください。** デスクトップや
OSの一時フォルダなど、リポジトリの外に置きます。
（過去にルート直下へ12枚溜まったため、`.gitignore` で弾くようにしています）
