# 大会運営ガイド

**応募締切から大会終了までに、何をどの順でやるかの手順書です。**
コマンドはコピーしてそのまま貼れます。表示される内容も実際のものを載せてあります。

サイトの直しかたは [詳細設計書](detail-design.md)、
画像の差し替えは [画像ガイド](image-guide.md) を見てください。

> **同じ内容の Excel 版が `docs/大会運営ガイド.xlsx` にあります。**
> 手順ごとにシートが分かれていて、最後のシートは印刷して使えるチェックリストです。
> **正本はこの Markdown のほう**なので、直すときはこちらを編集して
> `python tools/build_operation_xlsx.py` を流し直してください。

## 大会の形（先に全体像）

```
予選         N卓 ×3戦   各卓 1位   → 決勝
                        各卓 最下位 → 最下位決定戦
                        各卓 中間   → 順位決定戦
順位決定戦   ×3戦        合計点の上位 → 決勝／下位 → 最下位決定戦
決勝         1卓4人 ×3戦 → 1位が優勝
最下位決定戦 1卓4人 ×3戦
```

- **どの卓も3戦**打ち、**3戦の合計点**で順位を決めます
- **抽選するのは予選の卓だけ。** 先の卓は成績で決まります
- **誰でも最低2回は打てます**（予選で負けても終わりません）
- 対応する人数は **5〜16人（予選2〜4卓）**。17人以上は組めません（章4）

**シートに入れるのは点数だけです。** 順位も、次の段に誰が行くかも、
ページとスクリプトが計算します。詳しい決まりは
[詳細設計書 章7-1](detail-design.md) にあります。

## 1. 応募が締め切られたら（前日）

### 手順 1-1. 参加者のCSVを用意する

**Googleフォームの回答をスプレッドシートに出して、CSVで書き出すだけです。**
列を並べ替える必要はありません。

```csv
タイムスタンプ,お名前,ポカジャンを解放していますか
2026/08/10 21:03:11,ふろん,解放
2026/08/10 21:05:42,てるてる,未解放
```

見出しに「名前」「解放」という言葉が入っていれば、**その列を自動で見つけます。**
1列目がタイムスタンプでも問題ありません。

見出しが無い／言葉が違う場合は、1列目を名前・2列目を解放として読みます。
最低限これだけあれば動きます。

```csv
名前,解放
ふろん,解放
てるてる,未解放
```

解放の欄は、**空欄・「未」・「未解放」・「×」・「x」・「no」なら未解放**、
それ以外（「解放」「○」「o」「yes」など）は解放済みとして扱います。

### 手順 1-2. 抽選する

```bash
python tools/draw_tables.py 参加者.csv --save tournament.json
```

こう表示されます。

```
読んだ列: 名前 = 1列目「名前」 / 解放 = 2列目「解放」
参加者 12人（解放 8 / 未解放 4）
抽選 seed: 814   ← 同じ結果を出すには --seed 814

[卓1]
   Fukagami  ルーム作成
   アオ（未解放）
   てるてる（未解放）
   花園美咲
[卓2]
   アシエンSS  ルーム作成
   しゃるろって（未解放）
   ふろん
   フク（未解放）
[卓3]
   どこばか  ルーム作成
   ねこみみ
   ぽち
   まる

進行（どの卓も3戦、3戦の合計点で順位）
   予選: 12人 / 3卓
   順位決定戦: 6人 / 2卓  空席2はCPU
   決勝: 4人 / 1卓
   最下位決定戦: 4人 / 1卓
```

**まず「読んだ列」を確認してください。** ここが違っていると、名前と解放を
取り違えたまま抽選されます。

- 各卓の**いちばん上の人が「ルーム作成」**です。解放している人が必ず1人入ります
- 4人に満たない卓には、そのまま開始すると**空席にCPUが入ります**
- `seed` を控えておけば、`--seed 814` で同じ卓分けを何度でも出せます

> **抽選するのは予選だけです。** 順位決定戦から先の卓は成績で決まるので、
> ここでは組みません。

### 手順 1-3. 進行に無理がないか見る

「気になる点」が出たら読んでください。**出なければそのままで大丈夫です。**

```
気になる点
   - 順位決定戦は6人で2卓のため、2席がCPUになります。
   - 順位決定戦から先の卓は成績で決まります。**ポカジャンを解放している人がその卓に1人もいないと、ルームを立てられません。** そのときは運営が席を入れ替えるか、解放している観戦者に立ててもらってください。
```

**最後の1件は毎回出ます。** 予選の抽選では各卓に解放者を1人ずつ置けますが、
**順位決定戦から先の顔ぶれは成績で決まるので、そこまでは面倒を見られません。**
決勝の4人が全員未解放、ということが起こりえます。当日その場で気づけるよう、
**卓が組まれた時点で解放者がいるか一度見てください。**

**席がちょうど埋まるのは 8人・12人・16人だけです。** それ以外はどこかにCPUが入ります。

### 手順 1-4. Discordに貼る用がほしいとき

```bash
python tools/draw_tables.py 参加者.csv --seed 814 --md
```

そのままコピーして貼れる形で出ます。**卓分けを当日発表する方針なら、これは当日でOKです。**

## 2. 当日

### 手順 2-1. 予選の卓分けをスプレッドシートに貼る

前日に出した卓分けを、スプレッドシートに貼り付けます。列は6つです。

| 回戦 | 卓 | 参加者 | 1戦目 | 2戦目 | 3戦目 |
|---|---|---|---|---|---|
| 予選 | 卓1 | ふろん | | | |
| 予選 | 卓1 | てるてる | | | |

**「回戦」の欄には「予選」と書いてください。** ここが違うと、次の段が作れません。

貼り付けた時点で、**サイトを開き直せばもう表示されます。**

> **初回だけ、シートの用意が必要です。** やりかたは章6を見てください。
> 一度そろえてしまえば、当日は点数を入れるだけになります。

### 手順 2-2. 1戦ごとに点数を入れる

**スプレッドシートの「1戦目」「2戦目」「3戦目」に点数を入れるだけです。**
パソコンでもスマホでも、Googleスプレッドシートが開ければ誰でもできます。

| 回戦 | 卓 | 参加者 | 1戦目 | 2戦目 | 3戦目 |
|---|---|---|---|---|---|
| 予選 | 卓1 | ふろん | 12300 | 8400 | 15100 |
| 予選 | 卓1 | てるてる | 9200 | 11000 | 7300 |
| 予選 | 卓1 | アシエンSS | 8100 | 9000 | 6400 |
| 予選 | 卓1 | どこばか | 5400 | 6100 | 4900 |

- **全角の数字でも、カンマ区切り（`12,300`）でも読めます**
- **空欄は「まだ入れていない」という意味です。0 と書かないでください。**
  0点と未入力を混ぜると、対局中の卓に順位が出てしまいます
- **1人でも3戦そろっていない卓は「対局中」**と表示され、順位も出ません
- **メモ用の列を足しても構いません。** 見出しの言葉（回戦／卓／参加者／1戦目…）で
  列を探すので、順番を入れ替えても動きます

#### 「勝ち」の列は自動で埋まります

`勝ち`（または `結果` / `行き先`）という見出しの列を置いておくと、
**「次の段を作る」を押すたびに、決着した卓の行き先が書き込まれます。**

| 回戦 | 卓 | 参加者 | … | 勝ち |
|---|---|---|---|---|
| 予選 | 卓1 | ふろん | | 勝ち（決勝へ） |
| 予選 | 卓1 | てるてる | | 順位決定戦へ |
| 予選 | 卓1 | アシエンSS | | 順位決定戦へ |
| 予選 | 卓1 | どこばか | | 負け（最下位決定戦へ） |
| 決勝 | 卓1 | ふろん | | 優勝 |

- **この列は手で書かなくて大丈夫です。** 書いても次に押したときに上書きされます
- **CPUの行は空のまま**です（順位に入れていないため）
- **表示には一切使いません。** シートを見て進行を追うためだけの列です
- **決勝が終わったあとにもう一度押すと、「優勝」「2位」…が入ります。**
  行は増えず、「ここが最後です」と出るだけなので安心して押してください
- 列が無ければ何も起きません。要らなければ消して構いません

3戦そろうと、その卓は**合計点の高い順に並べ替わり**、印が付きます。

| 表示 | 意味 |
|---|---|
| 金色・✦ | **決勝へ進む人**（予選の1位／順位決定戦の上位） |
| 灰色・▽ | **最下位決定戦へ進む人**（予選の最下位／順位決定戦の下位） |
| 印なし | 順位決定戦へ進む／そこで順位確定 |
| 王冠・「優勝」 | 決勝の1位。**最下位決定戦の1位には付きません** |

> **13人以上（予選4卓）になると、順位決定戦に印が1つも付きません。**
> 決勝の4席が予選の1位だけで埋まるため、そこから上がる席が残らないからです。
> 壊れているわけではないので、見出しに**「（ここで順位が決まります）」**と出ます。
> 12人（予選3卓）なら、上下に1人ずつ動きます。

> **CPUの行はそのままにしてください。** CPUは順位に入れないので、
> 点数を入れても入れなくても、次に進む人は変わりません。
> 以前あった「CPUが上位に入ったら繰り上げる」手作業は不要になりました。

#### 次の段の行は、ボタンを押すと増えます

その段の点数を入れ終わったら、**「次の段を作る」を押してください。**
次の段の行がシートに追加されます（薄い黄色で色が付きます）。

押しかたは3つあります。**どれも同じことをします**（章6-3で用意します）。

| | 押しかた | 使える場所 |
|---|---|---|
| 1 | メニューの「ポカジャン大会 → 次の段を作る」 | パソコン |
| 2 | シートに置いた図形ボタン | パソコン |
| 3 | 「実行」列のチェックボックス | **スマホでも押せます** |

**勝手には増えません。** 押したときだけ動くので、入力の途中で組まれる心配はありません。

**作れないときは、画面の右下に理由が出ます。**

```
予選の 卓2 に、まだ点数がそろっていません（3戦ぶん全員の点数が要ります）。
```

押す回数は**2回だけ**です。

1. 予選が全卓そろったら押す → **順位決定戦**の行ができる
2. 順位決定戦が全卓そろったら押す → **決勝と最下位決定戦**の行が同時にできる

```
順位決定戦を作りました（6人／2卓）。各卓3戦ぶんの点数を入れてください。
決勝と最下位決定戦を作りました（合わせて8人）。
```

順位決定戦へは、**2位と3位が両方の卓に混ざるように**配ります。
出身の卓も散ります。

```
予選  卓1 → 2位A, 3位D          順位決定戦  卓1 = A, C, F
      卓2 → 2位B, 3位E                      卓2 = B, D, E
      卓3 → 2位C, 3位F
```

**予選の卓順のまま配ると「2位だけの卓」と「3位だけの卓」に分かれます。**
この方式は素点で比べるので、それだと不公平になります。だから混ぜています。

**組み合わせを手で決めたいときは、追加された行を書き換えてかまいません。**
一度作られた行が勝手に作り直されることはありません。

> **同点があったときは、ひとこと知らせます。**
> 「上の行を上位として扱っています」と出るので、それでよければそのまま、
> 変えたければ行を入れ替えてください。**黙って決めることはしません。**

### 手順 2-3. サイトを開き直す

**それだけです。** ページを開くたびにスプレッドシートを読みに行くので、
`git` も `python` も要りません。反映まで**数十秒**かかることがあります。

**次の段も 2-2 の繰り返しです。**

> **まだシートに無い段も、前の段が終わっていれば「（予定）」として先に出ます。**
> 誰がどこへ行くかは、ボタンを押す前から表で確認できます。

### 手順 2-4. 決勝と最下位決定戦

**この2つは同時に立ちます。** 表でも横に並んで出ます。

- **決勝**は金の枠。3戦そろうと1位に王冠と「優勝」が付き、表の中に紙吹雪が降ります
- **最下位決定戦**は通常の枠。**1位に「優勝」は出ません**（順位を確定させる卓です）

進行としては、**2卓を同時に動かして構いません。** VCも2つ用意しておいてください。

### 手順 2-5. 最高得点者を出す

**シートに入れた点数がそのまま使えます。** 別集計は要りません。

- 表彰するのは**1戦の点数がいちばん高かった人**です（合計ではありません）
- 全部の段・全部の卓の点数から、**いちばん大きい数字**を探してください
- **CPUは表彰の対象外です。** CPUの点数がいちばん高くても、人のなかの最高点を取ります

> **結果画面は数秒で自動的に切り替わります。** 撮り逃しは起きる前提で構えてください。
> 参加者には「同卓の1人ぶんで十分」「撮り逃したら自己申告」と案内してあります
> （サイトの RULE「最高得点者」と FLOW 04）。

- **送り先を先に決めて、卓分けの案内と一緒に伝えてください。** 主催者のDMでも、
  専用チャンネルでもかまいません
- **必要なのは卓ごとに1枚 × 3戦ぶん**です。届いていない卓は、その卓のVCで声をかけてください
- **撮り逃した戦は、点数の自己申告を集めてください。** 同卓の人の申告と食い違ったら、
  その卓の4人に確認します

結果発表で読み上げてください（サイトの FLOW 06）。

### （任意）最終結果をページに焼き付ける

大会が終わったあと、スプレッドシートを消しても表が残るようにしたいときだけ、
主催者のパソコンで次を実行します。**当日は不要です。**

```bash
python tools/update_bracket.py tournament.json
git add -A && git commit -m "最終結果" && git push
```

`tournament.json` の `scores` に、シートと同じ点数を写してから実行してください。

```json
{"name": "ふろん", "scores": [12300, 8400, 15100]}
```

## 4. うまくいかないとき

### 「同じ名前が複数あります」

```
同じ名前が複数あります: A
当日の呼び分けができないので、区別できる名前にしてください。
```

CSVに同じ表示名が2人います。当日どちらを呼んでいるか分からなくなるため止めています。
片方に印を付けるなどして区別してください。

### 「解放している人が足りません」

```
解放している人が足りません。2卓に対して解放者は1人です。
各卓にルームを作れる人が1人ずつ要るので、卓を減らす（＝1卓あたりの人数を増やす）か、解放者を増やしてください。
```

**予選の各卓にルームを作れる人が1人ずつ必要**なので、解放者が卓数より少ないと組めません。
当日その場で解放してもらうか、卓数を減らす（人数の多い卓を作る）判断が要ります。

### 「予選が5卓になります」「運営に相談してください」

```
参加者が17人だと予選が5卓になります。
5卓以上（17人以上）は予選を2段に分ける必要があり、いまの仕組みでは組めません。運営に相談してください。
```

**17人以上には対応していません。** 予選をもう1段挟む形にしないと、決勝の席（4つ）に
予選1位が収まりません。そうなったら、次のどれかを決めてください。

- **予選を2回に分けて開催する**（別日にする）
- **一部の方に観戦に回ってもらう**
- **仕組みを作り直す**（`docs/detail-design.md` 章7-1 の段構成から見直しが要ります）

### 表が「当日をお楽しみに」のまま変わらない

スプレッドシートが読めていません。上から順に確かめてください。

1. **`index.html` の `data-sheet` にIDが入っているか**（章6-4）。空だと何も読みに行きません
2. **共有設定が「リンクを知っている全員」になっているか**（章6-2）。
   自分だけが見られる状態だと、サイトからは読めません
3. **シート名が合っているか。** タブの名前を変えたなら `data-sheet-name` にも同じ名前を入れます
4. **見出しの行があるか。** 1行目は `回戦 / 卓 / 参加者 / 1戦目 / 2戦目 / 3戦目` にしてください
5. 少し待ってから開き直す。反映まで数十秒かかることがあります

読めなくても**ページの他の部分は普通に動きます**。表だけが出ない状態です。

### 卓が「対局中」のまま順位が出ない

その卓の**誰か1人でも3戦のどれかが空**だと、順位は出ません。
**わざとそうしてあります**（対局の途中で順位が出てしまわないようにするため）。

CPUの行は空のままで構いません。順位に入れていないためです。

### 次の段が出てこない

前の段の**どれか1卓でも3戦そろっていない**と、次には進みません。
全部の卓の点数が埋まっているか確かめてください。

### 「次の段を作る」を押しても増えない

**押すと、画面の右下に理由が出ます。** まずそれを読んでください。

| 出る文 | どうするか |
|---|---|
| 「〜に、まだ点数がそろっていません」 | その卓の3戦を入れてください |
| 「決勝と最下位決定戦まで組み終わっています」 | もう最後まで来ています。正常です |
| 「『予選』の行がありません」 | 「回戦」の欄を「予選」にしてください |
| 「予選が1卓しかありません」 | この方式は2卓以上（5人以上）で使います |
| 「予選が5卓あります」 | 17人以上は組めません（上記） |
| 「シートの見出しが読めません」 | 1行目を「回戦 / 卓 / 参加者 / 1戦目 / 2戦目 / 3戦目」にしてください |

> 「※同点がありました」は**注意書きであって失敗ではありません。**
> 行はもう作られています。順番を変えたいときだけ、行を入れ替えてください。

何も出ない場合は、スクリプトが入っていないか承認がまだです。
拡張機能 → Apps Script を開き、コードが貼られているか確認してください。

### 点数を入れたのに順位がおかしい

- **0 と空欄を混ぜていませんか。** 空欄は「未入力」です。0点なら `0` と書いてください
- **CPU の名前が `CPU` になっていますか。** 別の名前だと人として順位に入ります
- **同点ではありませんか。** 同点は上の行が上位になります。ひとこと知らせが出ています

### 「承認が必要です」と出る／「Google で確認されていません」から先に進めない

**初回だけ出ます。異常ではありません。** 手順は章6-3の「承認のしかた」を見てください。

「このアプリは Google で確認されていません」の画面では、
**左下の小さな「詳細」** → **「（安全ではないページ）に移動」** と進みます
（英語表示のときは `Advanced` → `Go to … (unsafe)`）。

**それでも進めない場合は、会社や学校の Google アカウントで
管理者が承認をブロックしている可能性があります。** 個人アカウントで開き直すか、
下の方法に切り替えてください。

> **承認を通さずに済ませる方法があります。**
> **「実行」列のチェックボックスなら承認は要りません**（章6-3）。
> メニューもボタンも使わず、これだけで当日の操作は足ります。
> **承認で行き詰まったら、無理に通さずこちらを使ってください。**

### メニューやボタンが出ない

**スマホのアプリでは、メニューも図形ボタンも表示されません。**
「実行」列のチェックボックス（章6-3）を使ってください。

パソコンでメニューが出ないときは、**スプレッドシートを開き直して**ください。
メニューはシートを開いたときに作られます。

### 「決勝」なのに「優勝」と出ない

シートの「回戦」欄が**ちょうど「決勝」になっているか**確かめてください。
**「優勝」が出るのは「決勝」の段だけです。** 「最下位決定戦」には出ません（正常です）。

決勝の**4人全員が3戦そろう**まで順位は出ません。1人でも空だと王冠も出ません。

### 「BRACKET:START / BRACKET:END が見つかりません」

`index.html` からマーカーのコメントを消してしまっています。
消してしまった場合は BRACKET セクションの中に、次の2行を戻してください。

```html
      <!-- BRACKET:START -->
      <!-- BRACKET:END -->
```

### 書き換わってほしくないのに上書きされる

`<!-- BRACKET:START -->` 〜 `<!-- BRACKET:END -->` の**間は毎回作り直されます。**
手で書いた内容は次の実行で消えます。前後の文章（見出しやリード文）は消えません。

### とりあえず結果だけ見たい

```bash
python tools/update_bracket.py tournament.json --dry
```

`index.html` を書き換えずに、出力される内容だけ確認できます。

### この JSON は古い形です、と言われる

```
この JSON は古い形（rounds / winners）です。
draw_tables.py --save で作り直してください。点数を入れる形に変わりました。
```

勝ち上がりトーナメントだったころの `tournament.json` です。
`python tools/draw_tables.py 参加者.csv --save tournament.json` で作り直してください。

## 6. スプレッドシートの用意（最初の1回だけ）

### 手順 6-1. シートを作る

Googleスプレッドシートを新規作成し、1行目に見出しを入れます。

| 回戦 | 卓 | 参加者 | 1戦目 | 2戦目 | 3戦目 |
|---|---|---|---|---|---|

`tools/bracket-sheet.example.csv` をインポートすると、この形が入った状態から始められます。

> **見出しに無い列を足しても構いません。** 古い「勝ち」列が残っていても、
> ページもスクリプトも**読み飛ばします**ので害はありません。
> ただし当日に「ここに何か入れるのか」と迷わせるので、**消しておくと安心です。**

#### シートを「テーブル」にしているとき

見出しに▽が付く（Googleスプレッドシートのテーブル機能を使っている）場合、
**「回戦」列のドロップダウンに次の4つを入れておいてください。**

```
予選 / 順位決定戦 / 決勝 / 最下位決定戦
```

スクリプトが足す行には「順位決定戦」などが入ります。
選抜肢に無いと**値は入るものの警告の印が付き**、壊れたように見えます。
別にどちらでもよければ、ドロップダウンを外してしまっても構いません。

**卓の列にもドロップダウンを使っているなら**、`卓1` 〜 `卓4` まで入れておいてください。

### 手順 6-2. 「リンクを知っている全員」に共有する

右上の「共有」→ 一般的なアクセス →「リンクを知っている全員」→ **閲覧者**。

> **編集者ではなく閲覧者にしてください。** サイトは読むだけなので閲覧権限で足ります。
> 更新を任せる人には、別途「編集者」として個別に追加してください。

### 手順 6-3. 「次の段を作る」を押せるようにする

**これを入れると、順位決定戦や決勝の行を作れるようになります。** 入れないと、
表には次の段が「（予定）」で出るものの、**点数を書き込む行がシートに無い**状態になります。

まずスクリプトを入れます。

1. スプレッドシートを開く
2. 上のメニューから **拡張機能 → Apps Script**
3. 出てきたコードを全部消して、**`tools/bracket.gs` の中身を貼り付ける**
4. 保存（フロッピーのアイコン）
5. スプレッドシートを開き直す
   → 上に **「ポカジャン大会」というメニューが増えます**
6. 「ポカジャン大会 → 次の段を作る」を一度押す
   → **初回だけ承認を求められます**（次の「承認のしかた」へ）

#### 承認のしかた（初回だけ・パソコン）

**途中で警告の画面が出ますが、異常ではありません。** 自分で貼り付けたスクリプトが
Googleの審査を受けていないだけで、中身はこの `bracket.gs` そのものです。

1. 「承認が必要です」→ **権限を確認**
2. 自分の Google アカウントを選ぶ
3. **「このアプリは Google で確認されていません」** と出る
   → 左下の **「詳細」** をクリック
   → **「（プロジェクト名）（安全ではないページ）に移動」** をクリック
4. 求められる権限は「**このスプレッドシートの表示と編集**」だけです → **許可**

一度通せば、次からは押すだけで動きます。

> **代わりの人がメニューやボタンを使う場合、その人も同じ承認が必要です。**
> **チェックボックス方式（下記）なら承認は要りません。** 当日に代理をお願いする
> 可能性があるなら、チェックボックスを用意しておくほうが確実です。

**メニューだけで足りるならここまでで完了です。** 押しやすくしたい場合は、
次のどちらかを足してください。

#### ボタンを置く（パソコン向け）

1. 挿入 → 図形描画 → 四角を描いて「次の段を作る」と書く → 保存して閉じる
2. 置かれた図形の右上の **「⋮」→ スクリプトを割り当て**
3. `createNextStage` と入力して OK

以後、その図形を押すだけで動きます。

> **関数名が `createNextRound` から `createNextStage` に変わりました。**
> 前のシートを使い回すときは、図形に割り当てた名前も入れ直してください。

#### チェックボックスを置く（**スマホでも押せる・承認も不要**）

**承認でつまずいたときは、これだけ用意すれば足ります。** メニューもボタンも要りません。

1. **空いている列の1行目に「実行」と入力する**
   （例：A〜Fを使っているなら H1。「実行ボタン」でも構いません）
2. **そのすぐ下のセル（例：H2）を選ぶ**
3. メニューの **挿入 → チェックボックス**
4. 隣のセルに「次の段を作る」と書いておくと、当日ほかの人が見て分かります
   （前のシートを使い回すなら、**「次の回戦を作る」のままになっていないか見てください**。
   押す回数は**2回だけ**になりました）

使うときは、その段の点数を入れ終わってから **チェックを入れるだけ**です。
行が追加され、**チェックは自動で外れます**（また押せる状態に戻ります）。

まだ入れ終わっていないときにチェックしても、行は増えません。チェックだけ外れます。

**この方法だけは承認が要りません。** セルの編集をきっかけに動く仕組み
（シンプルトリガー）は、権限を求めない範囲でだけ動くようGoogleが決めているためです。
このスクリプトは同じシートを読み書きするだけなので、その範囲に収まっています。

> **スマホのアプリでは、メニューも図形ボタンも出ません。**
> 代わりの人がスマホだけで進める可能性があるなら、
> **チェックボックスを必ず用意しておいてください。**
> 承認の手間もないので、頼むときの説明が「チェックを入れるだけ」で済みます。

### 手順 6-4. IDをページに書く

スプレッドシートのURLはこの形です。

```
https://docs.google.com/spreadsheets/d/【この部分がID】/edit#gid=0
```

`index.html` の `<!-- EDIT: 対戦表のスプレッドシートID -->` を探し、
`data-sheet="..."` にそのIDを貼ります。シート名を変えている場合は
`data-sheet-name="シート1"` も埋めてください（既定のままなら空でOK）。

```html
<div class="bracket" data-sheet="1AbCdEf...XyZ" data-sheet-name="">
```

そのあと commit して push すれば準備完了です。

> **IDが空のあいだは「当日をお楽しみに」が出たままになります。** 壊れはしません。

### 仕組みについて

サイトは Google の公開データ機能（gviz）を使ってシートを読んでいます。
**Googleのスプレッドシートは `Access-Control-Allow-Origin` を返さないため、
ふつうの読み込み方（fetch）では取得できません。** 実測して確認したうえで、
制限を受けない JSONP という方式にしてあります。

読めなかったとき（未設定・非公開・通信不良・JSが動かない）は、
**「当日をお楽しみに」の表示に戻るだけ**で、ページの他の部分は普通に動きます。
