# 大会運営ガイド

**応募締切から大会終了までに、何をどの順でやるかの手順書です。**
コマンドはコピーしてそのまま貼れます。表示される内容も実際のものを載せてあります。

サイトの直しかたは [詳細設計書](detail-design.md)、
画像の差し替えは [画像ガイド](image-guide.md) を見てください。

> **同じ内容の Excel 版が `docs/大会運営ガイド.xlsx` にあります。**
> 手順ごとにシートが分かれていて、最後のシートは印刷して使えるチェックリストです。
> **正本はこの Markdown のほう**なので、直すときはこちらを編集して
> `python tools/build_operation_xlsx.py` を流し直してください。

## 1. 応募が締め切られたら（前日）

### 手順 1-1. 参加者のCSVを用意する

**Googleフォームの回答をスプレッドシートに出して、CSVで書き出すだけです。**
列を並べ替える必要はありません。

```csv
タイムスタンプ,お名前,ポカジャンを解放していますか
2026/08/10 21:03:11,ふろん,解放
2026/08/10 21:05:42,てるてる,未解放
```

見出しに「名前」「解放」という言葉が入っていれば、**その列を自動で見つけます。**
1列目がタイムスタンプでも問題ありません。

見出しが無い／言葉が違う場合は、1列目を名前・2列目を解放として読みます。
最低限これだけあれば動きます。

```csv
名前,解放
ふろん,解放
てるてる,未解放
```

解放の欄は、**空欄・「未」・「未解放」・「×」・「x」・「no」なら未解放**、
それ以外（「解放」「○」「o」「yes」など）は解放済みとして扱います。

### 手順 1-2. 抽選する

```bash
python tools/draw_tables.py 参加者.csv --save tournament.json
```

こう表示されます。

```
読んだ列: 名前 = 1列目「名前」 / 解放 = 2列目「解放」
参加者 8人（解放 4 / 未解放 4）
抽選 seed: 814   ← 同じ結果を出すには --seed 814

[卓1]
   Fukagami  ルーム作成
   アオ（未解放）
   てるてる（未解放）
   花園美咲
[卓2]
   アシエンSS  ルーム作成
   しゃるろって（未解放）
   ふろん
   フク（未解放）

進行（各卓から上位2名が勝ち上がり）
   1回戦: 8人 / 2卓
   決勝: 4人 / 1卓
```

**まず「読んだ列」を確認してください。** ここが違っていると、名前と解放を
取り違えたまま抽選されます。

- 各卓の**いちばん上の人が「ルーム作成」**です。解放している人が必ず1人入ります
- 4人に満たない卓には、そのまま開始すると**空席にCPUが入ります**
- `seed` を控えておけば、`--seed 814` で同じ卓分けを何度でも出せます

### 手順 1-3. 進行に無理がないか見る

「気になる点」が出たら読んでください。**出なければそのままで大丈夫です。**

```
気になる点
   - 決勝が3人しかいません（1席がCPU）。--advance を変えるか、参加人数の区切りを調整すると4人にできます。
```

各卓から何名が勝ち上がるかは `--advance` で変えられます（既定は2名）。

```bash
python tools/draw_tables.py 参加者.csv --advance 2 --save tournament.json
```

> **上位1名だけにすると人数が急に減ります。** 10人なら決勝が3人になり、
> 決勝までCPU入りになります。基本は既定の2名のままで問題ありません。

### 手順 1-4. Discordに貼る用がほしいとき

```bash
python tools/draw_tables.py 参加者.csv --seed 814 --md
```

そのままコピーして貼れる形で出ます。**卓分けを当日発表する方針なら、これは当日でOKです。**

## 2. 当日

### 手順 2-1. 卓分けをサイトに出す

```bash
python tools/update_bracket.py tournament.json
```

```
1回戦: 2卓（結果が入っているのは 0卓）

index.html を更新しました。公開するには commit して push してください。
```

続けて公開します。

```bash
git add -A
git commit -m "1回戦の卓分け"
git push
```

数十秒で GitHub Pages に反映されます。参加者はページを開き直すだけです。

### 手順 2-2. 対局が終わったら結果を書く

`tournament.json` をテキストエディタで開き、**その卓の `winners` に勝ち上がった人の名前**を書きます。

```json
{
  "vc": "卓1",
  "players": ["Fukagami", "アオ", "てるてる", "花園美咲"],
  "winners": ["Fukagami", "花園美咲"]
}
```

- 名前は `players` に書いてあるものを**そのままコピー**してください
- 人数は勝ち抜け数（既定2名）と同じにします
- **まだ終わっていない卓は `[]` のままで大丈夫です**

### 手順 2-3. 反映する

```bash
python tools/update_bracket.py tournament.json
```

全卓の結果がそろっていると、**次の回戦が自動で組まれます。**

```
1回戦: 2卓（結果が入っているのは 2卓）
決勝: 1卓（結果が入っているのは 0卓）

次の回戦を 1 つ組みました（tournament.json に保存済み）。

index.html を更新しました。公開するには commit して push してください。
```

あとは push するだけです。

```bash
git add -A && git commit -m "1回戦の結果" && git push
```

**2回戦以降も 2-2 → 2-3 の繰り返しです。**

### 手順 2-4. 決勝

決勝の `winners` には**優勝者1名だけ**書いてください。
そこだけ濃い金色で「優勝」と表示されます。

```json
{ "vc": "卓1", "players": ["Fukagami", "花園美咲", "ふろん", "アシエンSS"], "winners": ["ふろん"] }
```

## 4. うまくいかないとき

### 「同じ名前が複数あります」

```
同じ名前が複数あります: A
当日の呼び分けができないので、区別できる名前にしてください。
```

CSVに同じ表示名が2人います。当日どちらを呼んでいるか分からなくなるため止めています。
片方に印を付けるなどして区別してください。

### 「解放している人が足りません」

```
解放している人が足りません。2卓に対して解放者は1人です。
各卓にルームを作れる人が1人ずつ要るので、卓を減らす（＝1卓あたりの人数を増やす）か、解放者を増やしてください。
```

**各卓にルームを作れる人が1人ずつ必要**なので、解放者が卓数より少ないと組めません。
当日その場で解放してもらうか、卓数を減らす（人数の多い卓を作る）判断が要ります。

### 「〜に『◯◯』がいません」

```
1回戦 卓1 に「ふくがみ」がいません。その卓の参加者は Fukagami、アオ、てるてる、花園美咲 です。名前の表記を合わせてください。
```

`winners` に書いた名前が、その卓の `players` と一致していません。
**表示されている名前をそのままコピーしてください。** 大文字小文字や表記ゆれも区別します。

### 「BRACKET:START / BRACKET:END が見つかりません」

`index.html` からマーカーのコメントを消してしまっています。
消してしまった場合は BRACKET セクションの中に、次の2行を戻してください。

```html
      <!-- BRACKET:START -->
      <!-- BRACKET:END -->
```

### 書き換わってほしくないのに上書きされる

`<!-- BRACKET:START -->` 〜 `<!-- BRACKET:END -->` の**間は毎回作り直されます。**
手で書いた内容は次の実行で消えます。前後の文章（見出しやリード文）は消えません。

### とりあえず結果だけ見たい

```bash
python tools/update_bracket.py tournament.json --dry
```

`index.html` を書き換えずに、出力される内容だけ確認できます。
