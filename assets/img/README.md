# 画像を置く場所

ここにファイルを置くと、ページに自動で反映されます。**置かなければ何も表示されません**（壊れた画像アイコンも出ませんし、見出しだけが残ることもありません）。

## いま入っている画像（生成AIによる二次創作）

`tools/generate_nene.py` で作ったものです。作り直しかたは本体の README を見てください。

| ファイル | 使われる場所 |
|---|---|
| `nene.webp` | ヒーロー右下。カードを見せているポーズ |
| `nene-about.webp` | ABOUT の本文の下 |
| `nene-entry.webp` | ENTRY の受付ボタンの横 |
| `nene-splash.webp` | ローディング画面の丸いメダル |
| `nekko.webp` | 流れる帯の区切り、フッター |
| `ogp.jpg` | Discordに貼ったときのリンクプレビュー（1200×630） |

## これから置くもの：ポカジャンの画面

**ご自身のプレイ画面を撮って** ここに置いてください。置いたぶんだけ RULE セクションの「実際の画面」に並びます。1枚も置かなければ、その見出しごと出ません。

| ファイル名 | 撮ってほしい場面 |
|---|---|
| `shot-1.png` | 配牌された直後の手札 |
| `shot-2.png` | 役がそろって「ポカジャン」を宣言できる状態 |
| `shot-3.png` | 対局が終わった結果画面（獲得コインが見えるもの） |

- スマホの縦長スクショで大丈夫です。枠の中に収まるよう自動で調整されます
- ファイル名は上記のとおりにしてください（`.png` 固定）
- 説明文は `index.html` の `<!-- EDIT: スクショ〇枚目の説明 -->` で変えられます
- 他人のIDや個人情報が写り込んでいないか、置く前に確認してください

スクショを置くと、フッターに「ゲーム画面は『ホロライブドリームス』より引用。著作権はカバー株式会社に帰属します」の一文が自動で出ます。

## 使ってよい画像・いけない画像

このサイトは[ホロライブプロダクション二次創作ガイドライン](https://hololivepro.com/terms/)に沿って非営利で運営する前提です。

**置いてよいもの**

- 自分で描いた、または生成したファンアート
- 描き手から掲載の許諾をもらったファンアート
- 自分のプレイ画面のスクリーンショット

**置いてはいけないもの**

- 公式サイト・公式X・配信画面などから取ってきた**公式イラスト、公式ロゴ、公式グッズ写真**
- 他人のファンアートを無断で持ってきたもの
- 攻略サイトなど、他サイトに載っている画像

ガイドラインは「創意工夫のある創作」を非営利で認めるものです。公式素材の著作権はカバー株式会社が留保しており、転載は認められていません。「公式と誤解されうるもの」も禁止事項です。

## 生成した画像を採用する前に

このモデルは、画像の隅に署名や **「© COVER Corp」風の偽の著作権表記** を描くことがあります。そのまま載せると公式と誤解されます。

- 生成スクリプトが、切り抜き後に孤立した小さな塊を自動で除去します
- それでも取りこぼすことがあるので、**採用前に必ず四隅を目視で確認**してください

## ファイル形式について

キャラクターの切り抜きは **WebP**（透過つき）です。同じ絵柄でPNGの約1/6に収まるため採用しています。主要なブラウザはすべて対応しています。

差し替えるときもWebPを推奨しますが、PNGでも動きます。その場合は `index.html` の `src` の拡張子も合わせて変更してください。

## クレジットを入れる場合

他の方のイラストを許諾を得て使うときは、`index.html` のフッター（`<!-- EDIT: 問い合わせ先 -->` の近く）に「イラスト：〇〇さん」の1行を足してください。
